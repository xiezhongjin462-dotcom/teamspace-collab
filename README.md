# 协作间

一个中文小组协作网站前端原型，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 本地预览

直接用浏览器打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 已实现的可交互原型

- 个人主页、项目列表与项目详情
- 新建项目、前期讨论与资料收集界面
- 开启正式协作阶段
- 随机/手动分工入口、成员工作进度卡片与详情评论入口
- 项目邀请链接和密码展示、置顶共享链接
- Word、PDF、PPT、图片等文件选择入口
- 桌面与移动端响应式布局

项目内容、用户登录、邀请链接和评论目前是界面演示数据；文件选择不会上传文件。数据不会同步到其他浏览器或设备。

## 上线为多人可用服务所需工作

要实现任何用户跨设备访问并共同使用，需要部署前端，并增加服务端能力：账号认证、项目与成员权限、项目密码校验、实时数据同步、文件对象存储，以及域名与 HTTPS。当前工作区没有已连接的部署服务或云端凭证，因此这里交付的是可预览的前端原型，尚未生成公网网址。
